# 稳定登记引用实验收尾（2026-11-09）

本页记录 `988ea2c` 的历史收尾。后续 Arena 扫描下界优化见
[新一轮采用决定](ARENA_MIXED_OPTIMIZATION.md)；全局登记仍沿用本页的 token 策略。

本轮已完成离线独立审计，**稳定登记引用不进入通用主线默认实现**。
生产核心继续使用 `d2b6aa3` 的 token 查找策略；候选保存在
`codex/claim-reference-experiment-20261109` 实验分支。主线仅保留基准、
first-fit 回归、CI 功能检查和本轮证据，不新增生产依赖或修改公开 ABI。

## 候选与采用决定

本轮先后否决了长期保留已选 shape 和减少提示写入两项缓存调校。
随后比较稳定登记节点引用的两种表示：v1 在本机 x64 Release 中使
`Backing` 从 80 增至 88 字节；v2 利用已有字段间隙保存活动标记，
`Backing` 恢复为 80 字节，`RangeClaim` 与 domain 大小也与基线一致。
结构大小不是 malloc 元数据、RSS、Android 布局或内存节省证据。

v2 在逆序和打散释放的完整流程中观察到收益，但 Arena mixed/tiny
反向检查同时出现代价。该候选影响公共核心分配路径，当前证据不足以
证明它适合所有调用方，因此保留实验，不切换默认、不新增策略开关。

## 独立复核与数据范围

- 语义复核未发现受支持路径上的悬空 iterator、重复删除、重叠检查弱化
  或计费合同回归。失败／未知回调仍保留 claim 与计费并隔离域。
- 既有 v2 核心 23/23、C++ 12/12、ASan 23/23 的源码及日志摘要均匹配。
  ASan 不证明所有并发交错；TSan 未运行，隔离域也不构成无泄漏证明。
- arm64 三种核心功能模式通过。冻结的 31 项输入、160 个性能进程、
  80 对及 20 个分组经独立回读，未补样、剔样、重试或混池。
- arm64 采集收据已有末尾空闲观察及 boot 核对。本次收尾仅离线读取，
  未新增设备命令。该观察不是共享设备锁，也不说明设备当前状态。
- 宿主 v2 的释放和 Arena 反向检查另有 160 个进程，独立重算后分别保留；
  两项缓存与 v1 的旧轮次也保留，不由后续结果覆盖。

下列比值是 **candidate / baseline 的逐对耗时比中位数**。小于 1
表示该组观察到较低耗时；每组仅四对，不构成产品性能资格或普遍收益。

| arm64 工作负载 | 完整流程 P50 配对比 | 解释 |
|---|---:|---|
| 1 域、逆序释放，1 / 4 线程 | 0.571 / 0.566 | 包含分配、写读、释放和关闭 |
| 32 域、逆序释放，1 / 4 线程 | 0.475 / 0.337 | 同上 |
| 打散释放，全部 1 / 32 域及线程组 | 0.590–0.638 | 同上 |
| 32 域、前向释放，1 线程 | 1.015 | 保留不利对照 |
| Arena main mixed，4 线程 | 1.378 | 完整流程 4/4 对变慢，分配批次 P50 比约 3.458 |
| Arena tiny fixed，1 线程 | 1.420 | 完整流程 2/4 对变慢 |
| Arena tiny mixed，1 线程 | 1.065 | 完整流程 3/4 对变慢 |

多线程 Arena mixed 的部分配对实际 peak backing 不同。相同请求与字节
oracle 不保证相同线程交错或容量轨迹；逐对峰值必须随结果保留。
Arena 预分配／A 历史不在 B 阶段 workflow 计时内，不能与 claim 的
准备至关闭完整流程直接合并。P50/P95 是批次或轮次统计，不是单 API
调用延迟。CPU 频率、调度及其他活动未隔离，没有能耗、RSS 或正式产品收益。

主线收尾后重新构建验证：核心及可选 JNI 45/45、C++ 12/12，两个安装后基准的 A/A 功能配对各 12 个进程通过。[本次宿主回执](../artifacts/claim-release-20261109/main-host-validation.json)。
