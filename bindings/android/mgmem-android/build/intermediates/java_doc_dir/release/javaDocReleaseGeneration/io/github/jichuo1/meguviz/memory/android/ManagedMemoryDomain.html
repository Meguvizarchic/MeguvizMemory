Package io.github.jichuo1.meguviz.memory.android

Class ManagedMemoryDomain

  • All Implemented Interfaces:
    java.lang.AutoCloseable 
    
public final class ManagedMemoryDomain
 implements AutoCloseable

    Optional managed owner for the existing Memory core and bounded byte leases. No native address or direct ByteBuffer is exposed. Explicitly close owners, leases and the domain; GC is not a cleanup mechanism.

      Optional pressure controller bound to its existing managed domain. Pressure close never closes the domain. A domain close also detaches the controller before closing its core. Polling and snapshots belong on a worker; framework notifications only submit events.

         ManagedMemoryDomain.Pressure attachPressure(long moderateBytes, long criticalBytes)

        Opt in to pressure handling on this same domain. Attachment and budget transitions may return BUSY; retry on a worker. A zero manual budget is supported and is never raised by a pressure restoration event. Rebinding starts from the domain's current budget, not the detached binding's former manual target; explicitly setBudget to restore a higher target.

      • snapshot

         Array<long> snapshot()

        [managedState,coreState,budget,backing,reserved,peak,live,retiring, activeAllocations,activeLeases]. Active allocations include retiring allocations whose owner was released but still have leases. The managed and core state fields are sampled separately, not atomically. Null means unavailable for an unspecified reason; -1 means outside Java's signed range. Neither means zero or proves an API call stack has exited. A concurrent forget may make this return null or throw.
