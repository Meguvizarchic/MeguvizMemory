Package io.github.jichuo1.meguviz.memory.android

Class NativeMemoryLease

  • All Implemented Interfaces:
    java.lang.AutoCloseable 
    
public final class NativeMemoryLease
 implements AutoCloseable

    Bounded access to a native Memory lease registered by trusted native code. No native pointer or direct buffer escapes. Close may synchronously run the original owner/provider callback; use a suitable cleanup thread.

      • write

         synchronized void write(long offset, Array<byte> source, int arrayOffset, int count)

        Copies at most MAX_WRITE_BYTES to this exclusive WRITE lease. Staging admission/allocation failures and JNI exceptions leave native bytes unchanged. Separate calls commit separately; this does not promise crash-atomicity or atomic observation by aliases.

      • copyTo

         void copyTo(NativeMemoryLease destination, long sourceOffset, long destinationOffset, int count)

        Copies directly into another WRITE lease in this loaded runtime. Overlap, including self-copy, has memmove semantics. No Java array or native staging buffer is allocated. Each call commits independently. Tokens are admitted under separate short object locks; a transfer already admitted may complete while close starts, or fail before copying if native close wins. No two Java object monitors are held together.

      • close

         void close()

        Stops admission once and releases the lease outside this object's lock. A concurrent repeated close may return before that release finishes; only its first caller receives any error. A native failure is quarantined; a JNI exception may leave the result unknown. Neither permits retry.
